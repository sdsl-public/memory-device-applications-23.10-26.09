# Memory Device Application Landscape

Public report for **October 2023 – September 2026**.

**Current data cutoff: 2026-09-24.** The date range in the repository name is the target study window; it is not a claim that data through September 30 have been collected.

- Repository: https://github.com/sdsl-public/memory-device-applications-23.10-26.09
- Expected site after enabling GitHub Pages: https://sdsl-public.github.io/memory-device-applications-23.10-26.09/
- Candidate paper metadata: 4,531 records.
- Static, self-contained HTML with device–application networks, filters, evidence-paper metadata, 16:9 graph enlargement and SVG export.
- SRAM/DRAM device nodes are excluded from the displayed analysis. The source paper metadata are preserved.
- Memory computing and neuromorphic roles remain grouped for display; same-paper overlaps are deduplicated.

## Public content

The site contains titles, authors, venues, publication dates, DOI/publisher links, derived classifications and aggregate counts. No paper PDFs, full texts, full abstracts, or quoted evidence passages are included. Abstract availability and the source-field/sentence-index metadata for the earlier analysis may remain.

This is a candidate-corpus analysis, not a measurement of market share or a guarantee of scientific relevance for every paper.

## Publish once

1. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository root on `main`. Do not upload the ZIP file itself or an enclosing folder.
2. In **Settings → Pages → Build and deployment**, select **Deploy from a branch**.
3. Set **main** and **/(root)**, then save.
4. Check the Pages deployment status before sharing the expected site URL above.

## Update

Replace `index.html` with a regenerated **public-only** build and commit to the publishing branch. Do not upload the private analysis workspace, raw inventories, private reports, PDFs, or backups. No local WSL server is needed to keep the published report available.

The uploaded HTML is byte-identical to the prepared public report; this packaging step does not change its data, classifications, graph, or counts.
